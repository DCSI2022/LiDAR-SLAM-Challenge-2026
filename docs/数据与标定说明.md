# 正式比赛数据说明

## 数据文件

比赛包含两个 ROS1 bag，采集设备为 **Airy LiDAR（含内置 IMU）** 和 **Seeker 前部
左右两个鱼眼相机**：

| 场景 | 文件 | 时长 |
| --- | --- | ---: |
| `scene_0001` | `sequence_01_0000_0550.bag` | 约 550 s |
| `scene_0002` | `sequence_02_0560_0970.bag` | 约 410 s |

数据下载：

- 百度网盘：<https://pan.baidu.com/s/1c1jifyQrFvXWyAs64TCqRg>
- 提取码：`m2nt`

两个 bag 均为未压缩 ROS bag，只包含以下 topic：

| Topic | 类型 | 频率 |
| --- | --- | ---: |
| `/rslidar_front_points` | `sensor_msgs/PointCloud2` | 10 Hz |
| `/rslidar_front_imu_data` | `sensor_msgs/Imu` | 约 200 Hz |
| `/front_seeker/fisheye/left/image_raw/compressed` | `sensor_msgs/CompressedImage` | 约 20 Hz |
| `/front_seeker/fisheye/right/image_raw/compressed` | `sensor_msgs/CompressedImage` | 约 20 Hz |

LiDAR 点云包含 `x/y/z/intensity/ring/timestamp/feature`，其中逐点
`timestamp` 为 `float64`。

## 标定

- 两个赛道均提供 `calibration/lidar_imu.yaml`。
- LiDAR-Visual-Inertial 赛道额外提供 `calibration/front_stereo_omni.yaml`。
- 所有平移单位均为米，每个矩阵文件明确给出变换方向。

## 相机时间说明

比赛 bag 保留采集时的原始时间戳：

- `scene_0001` 在本场景约 `210.69 s` 时，相机 header 相对 LiDAR 额外落后约
  `1.002 s`。
- `scene_0001` 在此之前无需 1 秒补偿，此后应给图像时间增加约 `1.0 s`。
- `scene_0002` 全程位于偏移切换之后，应给图像时间增加约 `1.0 s`。
- `scene_0001` 每路相机各有 148 次相邻重复 header；`scene_0002` 各有 43 次。
- 没有发现相机、LiDAR 或 IMU header 倒退。

参赛算法应显式处理偏移切换和重复相机时间戳。固定 1 秒补偿不能覆盖完整的
`scene_0001`。

## 输出轨迹坐标点

提交轨迹表示 Airy LiDAR 内置 IMU 原点的位姿，位置单位为米。

## 时间戳与提交

评测时间戳、可靠区间和真值均不公开。参赛者按 bag 中的 LiDAR `header.stamp`
连续输出轨迹。提交必须包含：

```text
README.md
trajectories/scene_0001.txt
trajectories/scene_0002.txt
```

轨迹使用 TUM 格式：

```text
timestamp tx ty tz qx qy qz qw
```

时间戳必须严格递增。完成度不设硬性门槛，最大时间关联误差为 0.05 s；缺失部分会
通过 AUC 的 recall 分母降低成绩。两个场景文件仍然必须提交。

## 精度评定

每个场景对全部有效匹配位姿执行一次无尺度 SE(3) EVO 对齐，再计算平移 ATE、
AUC 和 RTE。

总分公式：

```text
Total Score = 100 * (
    0.40 * AUC
  + 0.40 * exp(-ATE / tau_ate_m)
  + 0.20 * exp(-RTE / tau_rte_pct)
)
```

RTE 使用 1/5/10 m 距离尺度。正式
`tau_ate_m=1.1542008644767718`、`tau_rte_pct=33.05656442344478`，公开参考结果总分为
`61.37093502233761`。

平台完整公开综合和逐场景的 RTE@1m、RTE@5m、RTE@10m。参考结果 总体三档
分别为 `52.102095%`、`18.970067%`、`12.436452%`；综合 RTE 仍为三档全部有效
归一化误差合并后的 RMSE `33.056564%`。
每个 scene 必须同时存在 1 m、5 m、10 m 有效 RTE 对。
